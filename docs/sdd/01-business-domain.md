# 01 - Business Domain

## Glosario del dominio

| Término | Descripción |
|---|---|
| Usuario | Persona registrada en la plataforma. Puede tener diferentes roles. |
| Rol | Permiso o tipo de usuario dentro del sistema. |
| Perfil | Información académica y competitiva asociada a un usuario. |
| Plataforma externa | Servicio externo de programación competitiva, por ejemplo Codeforces, LeetCode u otra plataforma definida por el equipo. |
| Handle externo | Identificador del usuario en una plataforma externa. |
| Equipo | Grupo de usuarios que practican juntos. |
| Membresía | Relación entre usuario y equipo. Puede representar pertenencia o solicitud pendiente. |
| Problema | Ejercicio o reto de programación asignable. |
| Asignación de problema | Relación entre un problema y un usuario/equipo asignado. |
| Envío o solución | Registro de una solución enviada por un usuario. |
| Recurso | Material de apoyo relacionado con un problema o tema. |
| Competencia | Evento competitivo donde participan usuarios o equipos. |
| Resultado de competencia | Registro del desempeño de un equipo o usuario en una competencia. |
| Progreso | Métrica de avance por usuario, equipo o tema. |
| Ranking | Ordenamiento interno por desempeño. |
| Debilidad | Tema o tipo de problema con menor nivel de resolución. |
| Asistente IA | Módulo de apoyo para consultas, recomendaciones y orientación. |
